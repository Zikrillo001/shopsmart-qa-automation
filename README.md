# ShopSmart QA Automation Framework

A portfolio-grade QA automation project for a web-based e-commerce platform.

## Project Overview
This project demonstrates a realistic QA automation framework covering:
- API testing
- UI testing
- Unit testing
- Robot Framework scenarios
- Reporting
- CI-ready structure

## Tech Stack
- Python
- Pytest
- Requests
- Playwright
- Robot Framework
- Allure / pytest-html

## Project Structure
```text
src/        -> framework code
tests/      -> pytest test suites
robot/      -> robot framework suites
data/       -> test data
config/     -> environment configs
docs/       -> manual QA documentation
reports/    -> generated reports
